# Dog Folder Icon Skill

Create a consistent set of minimalist dog-face folder icons from either a breed name or a real pet photo. Short prompts are supported: “给金毛做一套” or a pet photo plus “帮我做一套文件夹图标” automatically means the twelve canonical states as twelve separate transparent PNGs.

The skill locks the character's silhouette and markings while varying expressions by activity, so unrelated states do not all repeat the daily tongue-out face. Outputs use a 1024×1024 transparent cross-platform master with safe margins and small-size checks for macOS and Windows. Install-ready `.icns` and `.ico` files can be derived when explicitly requested and conversion tools are available.

Install by placing this folder in your agent's skills directory and reading `SKILL.md`. Reference images are style and placement anchors, not substitutes for the user's pet identity.
